# Sponsors

This page names the organisations that pay for or otherwise support the work on Agent Manifest.

Agent Manifest is sponsored by OPAQUE Systems, which funds the engineering, infrastructure and confidential-computing work behind it. Other organisations that want to support the project are welcome to join as sponsors.

The full sponsor list, and how to be added to it, are in [`SPONSORS.md`](https://github.com/agentrust-io/agent-manifest/blob/main/SPONSORS.md).
